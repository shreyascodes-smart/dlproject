# Reports go in docs/

Whenever you produce a report, audit, plan, analysis summary, or phase write-up for this project, also save it as a Markdown file in the `docs/` folder.

- File name: lowercase with underscores and the date, e.g. `docs/kiro_context_audit_2026-10-26.md`.
- Never overwrite an earlier report; create a new dated file instead.
- Never include secret values from `.env` files; refer to key names only.
